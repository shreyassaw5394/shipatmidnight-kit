# Security policy

Report vulnerabilities privately through GitHub: use "Report a vulnerability" under the Security tab of this repository (private vulnerability reporting). Please do not open a public issue for a security report.

This kit is a set of Markdown skills, agent definitions, a few small scripts and one shell script (`tools/skill-audit/audit.sh`). It has no server and collects no data. Relevant reports include: a skill or agent instruction that could make an agent take an unsafe action, a script that runs something unexpected, or a leaked secret.

This is a free project maintained by one person, provided as-is. Reports are read as time allows; there is no response-time commitment. Supported version: the latest release.
